```markdown id="x2p8mt"
# Bole Brew Café — Business Profile Card

A one-page styled profile card for the fictional Bole Brew Café in Addis Ababa.

## Files

- `index.html` — Profile card HTML
- `styles.css` — Page styling

## CSS Techniques Used

- CSS custom properties using `:root` and `var()`
- HSL color values
- Global `box-sizing: border-box`
- Google Fonts (Inter)
- CSS box model
- Padding, margin, border, and border-radius
- Centered card using `margin: auto`
- Typography hierarchy
- Line-height for readable text
- `:hover` pseudo-class
- HSL lightness change on button hover
- `::before` pseudo-element
- Responsive viewport setup
```
