# Habesha Eatery Mini-Site

A two-page accessible mini-site for the fictional Habesha Eatery restaurant in Bole, Addis Ababa.

## Pages

- `index.html` — Reservation form, menu table, image, and map.
- `contact.html` — Contact form and opening-hours table.

## How to Open

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to move between the Reservations and Contact pages.

## Accessibility Features

- Semantic HTML landmarks such as `header`, `nav`, `main`, `section`, and `footer`.
- One `h1` on each page.
- All form controls have associated labels.
- Email fields use `type="email"` for validation.
- Required form fields use the `required` attribute.
- Tables use captions and column headers with `scope="col"`.
- Images have meaningful alternative text.
- The map iframe has a descriptive `title`.
- Navigation uses keyboard-accessible links.
- The pages have unique titles and meta descriptions.
- The site was checked with the W3C HTML Validator.
