# React Dish Menu

This is a simple React project created using Vite. The project displays a header and a list of dishes with their names and prices.

The dishes are stored in an array and rendered dynamically using the `map()` method.

## Features

* React components
* JSX
* Props with destructuring
* Header component
* Dish component
* Rendering an array using `map()`
* Unique `key` for each dish

## How to Run the Project

1. Clone the repository:
bash
git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:

bash
cd your-project-name
3. Install the dependencies:
bash
npm install

4. Start the development server:

bash
npm run dev

5. Open the local URL shown in the terminal in your browser.
